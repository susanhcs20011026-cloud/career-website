01 / PRODUCT EDUCATION & FEATURE COMMUNICATION

Making Complex Product Features Easy to Understand

At Faithia, I worked on English-language product guidance that helped users discover platform features, understand livestream tools, and navigate creator services.

The goal was to translate product functionality into clear, actionable instructions supported by real interface screenshots.

FEATURE 01 / DISCOVER & LIVE

Helping Users Discover Live Content

Original user guide copy

To access Live & Replay:

  1. Open the app.
  2. Tap Discover in the bottom navigation bar.
  3. Scroll to the Live & Replay section.
  4. Tap any live stream or replay to watch.
01 Action-Oriented Language

Direct verbs—open, tap, scroll—make each action easy to follow.

02 Interface Consistency

Discover and Live & Replay match the interface labels, connecting the instructions to the screen.

03 Step-by-Step Clarity

The sequence moves from app navigation to watching content.

FEATURE 02 / GO LIVE

Guiding Creators From Setup to Broadcasting

Guide excerpt · Setup steps condensed

Enter Live Setup:

  1. Go to Discover.
  2. Tap the + button.
  3. Select Live.

Before going live, you can:

  • Add a cover image.
  • Enter a live title.
  • Add a description.
  • Enable replay.
  • Tap Go Live to begin streaming.

When replay is enabled, only livestreams longer than five minutes are saved for replay.

01 Progressive Guidance

Entry and configuration are separate stages, so creators can follow one decision at a time.

02 Feature Explanation & Expectation Setting

The cover, title, and description show what can be customized. The replay requirement appears before broadcasting begins.

03 Clear CTA

Go Live uses the exact interface label for the final action.

FEATURE 03 / LIVE INTERACTION & CONTROLS

Explaining Real-Time Livestream Tools

Guide excerpts · Grouped for this showcase

During a live stream, creators can:

  • View the number of viewers.
  • Tap Details to see the live title and description.
  • Turn the microphone on or off.
  • Turn the camera on or off.
  • Switch between front and rear cameras.
  • Send messages using the chat box.
  • View audience comments.
01 Feature Grouping

Information, audio/video controls, and audience interaction give the tools a clear structure.

02 Scannability

Short, parallel bullet points help creators locate the capability they need.

03 User-Centered Language

Each instruction describes an action creators can accomplish, beyond naming an icon.

FEATURE 04 / 1-ON-1 COACHING

Connecting Livestream Engagement With Coaching Services

Original user guide copy

During the live stream, viewers can discover and book coaching services.

They can:

  1. Tap the Book 1-1 Session card.
  2. Browse the available coaching offerings.
  3. Tap Book Session to schedule a coaching session.
01 Feature Discovery

Shows where viewers can access coaching from a livestream.

02 Benefit Communication

Connects audience engagement with creator services.

03 Task Completion

Ends at the visible booking action, keeping the path concrete.
